Markdown previews now look like a README on GitHub: bold, italic, code and links (Ctrl+click to open), headings, nested and task lists, quotes, tables and highlighted code blocks. In Quick Look, Markdown and Word documents sit on a page. The preview pane shows the item's type and size under its name, buttons to open it, choose the app, copy its path and see its properties, and the rest of its details below, each with an icon; long locations wrap. Tooltips are lighter.
