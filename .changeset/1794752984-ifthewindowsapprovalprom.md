If the Windows approval prompt for an update is declined, the update notice now stays and says why, with Try again, instead of disappearing; Settings › About shows "Not updated" rather than "Couldn't check".

<!-- zh-TW -->
更新時如果在 Windows 的權限確認視窗按了「否」，更新通知現在會留著說明原因並提供「再試一次」，不再直接消失；「設定 › 關於」也改顯示「未更新」，不再寫「無法檢查」。

<!-- zh-CN -->
更新时如果在 Windows 的权限确认窗口点了“否”，更新通知现在会留着说明原因并提供“再试一次”，不再直接消失；“设置 › 关于”也改显示“未更新”，不再写“无法检查”。
