Sorting by Type now follows the type name shown in the column, as in File Explorer, instead of the extension. Types Arke has no name for show the name Windows has for them (such as "AutoCAD Drawing"). Files whose registered icon is the file itself now show it.

<!-- zh-TW -->
依「類型」排序時改照欄位顯示的類型名稱，跟檔案總管一樣，不再照副檔名。Arke 沒有內建名稱的類型改顯示 Windows 的類型名稱（例如「AutoCAD 繪圖」）。圖示由檔案本身提供的類型現在也會顯示出來。

<!-- zh-CN -->
按“类型”排序时改按该列显示的类型名称，与文件资源管理器一致，不再按扩展名。Arke 没有内置名称的类型改显示 Windows 的类型名称（例如“AutoCAD 绘图”）。图标由文件本身提供的类型现在也会显示。
