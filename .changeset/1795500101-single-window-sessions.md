Single window mode, on by default: folders from other apps, Win+E and starting Arke again open as a tab in the window you used last ("Open in new window" still opens one). Last tabs now remembers every open window, not only the last one closed, and brings them all back.

<!-- zh-TW -->
單一視窗模式（預設開啟）：從其他程式開啟的資料夾、Win+E 和再次啟動 Arke 都會以分頁開在最近使用的視窗（「在新視窗開啟」仍開新視窗）。「上次的分頁」現在會記住所有開著的視窗，不再只記最後關閉的那個，下次啟動全部還原。

<!-- zh-CN -->
单一窗口模式（默认开启）：从其他程序打开的文件夹、Win+E 和再次启动 Arke 都会以标签页打开在最近使用的窗口（「在新窗口中打开」仍打开新窗口）。「上次的标签页」现在会记住所有打开的窗口，不再只记最后关闭的那个，下次启动全部还原。
