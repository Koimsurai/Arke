Folders now go in the sidebar's favorites: "Add to favorites" in a folder's or a tab's right-click menu (the tiles first, then the list below), or drag a tab, or a folder from Arke or File Explorer, onto the tiles or the list, where a mark shows where it goes. The list below the tiles is now called Favorites, and "Pin" is only for tabs.

<!-- zh-TW -->
資料夾現在放進側邊欄的「最愛」：在資料夾或分頁的右鍵選單按「加入最愛」（先放方塊，滿了放下方清單），或把分頁、Arke 或檔案總管裡的資料夾拖到方塊或清單上，會有標記顯示放進去的位置。方塊下方的清單改名為「最愛」，「釘選」只用在分頁。

<!-- zh-CN -->
文件夹现在放进侧边栏的“收藏夹”：在文件夹或标签页的右键菜单点“添加到收藏夹”（先放磁贴，满了放下方列表），或把标签页、Arke 或文件资源管理器里的文件夹拖到磁贴或列表上，会有标记显示放进去的位置。磁贴下方的列表改名为“收藏夹”，“固定”只用于标签页。
