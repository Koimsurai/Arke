Opening a network location Windows already knows is unreachable now says so with Retry, and opens it once the server is back, instead of showing an error number.

<!-- zh-TW -->
開啟 Windows 已知連不上的網路位置時，現在會說明連不上並提供「重試」，伺服器恢復後也會自動開啟，不再只顯示一串錯誤碼。

<!-- zh-CN -->
打开 Windows 已知连不上的网络位置时，现在会说明连不上并提供「重试」，服务器恢复后也会自动打开，不再只显示一串错误码。
