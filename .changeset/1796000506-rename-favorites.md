Favorites can be renamed: right-click a tile or a row in the favorites › Rename. The name shows only for the favorite (the folder keeps its own name everywhere else); an empty name brings the folder's name back. (#259)

<!-- zh-TW -->
最愛可以重新命名：在方塊或最愛清單的項目上按右鍵 →「重新命名」。這個名稱只顯示在最愛上（資料夾在其他地方仍是原本的名稱）；名稱留空就會恢復資料夾原本的名稱。（#259）

<!-- zh-CN -->
收藏项可以重命名：在磁贴或收藏夹列表的项目上右键 →“重命名”。这个名称只显示在收藏项上（文件夹在其他地方仍是原来的名称）；名称留空就会恢复文件夹原来的名称。（#259）
