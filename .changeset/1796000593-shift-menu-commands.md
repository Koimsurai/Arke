Right-clicking with Shift held adds the Windows commands that appear only then (such as Open PowerShell window here) to More options, as in File Explorer. (#272)

<!-- zh-TW -->
按住 Shift 再按右鍵時，「更多選項」會加入只在按住 Shift 時出現的 Windows 命令（例如「在這裡開啟 PowerShell 視窗」），跟檔案總管一樣。（#272）

按住 Shift 再右键时，“更多选项”会加入只在按住 Shift 时出现的 Windows 命令（例如“在此处打开 PowerShell 窗口”），与文件资源管理器一致。（#272）
