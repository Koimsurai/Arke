Properties counts `C:\Users\Default` instead of showing 0, and a count that misses other people's profiles you can't read (a drive, `C:\Users`, someone else's profile) now says "at least". Counting a folder on a spinning disk no longer starts over when the drive's file table can't answer, and folders the file table can't count are no longer read from it for nothing.
