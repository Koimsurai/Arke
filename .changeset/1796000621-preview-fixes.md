A damaged PDF can no longer stall or crash Arke while a folder's thumbnails load. Extracting a zip with some password-protected files now fails up front instead of leaving a half-extracted folder. A file named just `.gz` shows a name in the preview, and the preview details show the modified date once instead of twice.

<!-- zh-TW -->
損壞的 PDF 不會再在載入資料夾縮圖時卡住或讓 Arke 當掉。解壓縮含有部分加密檔案的 zip 時，會在一開始就失敗，不再留下解到一半的資料夾。檔名只有 `.gz` 的檔案預覽會顯示名稱，預覽詳細資料的修改日期也只顯示一次。

<!-- zh-CN -->
