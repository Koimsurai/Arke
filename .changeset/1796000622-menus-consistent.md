The menus of folders in the sidebar and on Home now match: favorites (tiles, list rows and Home cards), folders in the tree, drives and network places have the same rows in the same order, with Open in Terminal, Open in Windows File Explorer, Copy path and Properties for every folder. These menus also look like the file list's: an icon on each row, keys on the right (Ctrl+click for "Open in new tab"), and lines between groups. Drive names keep their letter when cut short, a drive's free space has a tooltip, the "Add to favorites" spot is no longer cut off, and the tiles are no longer left cut in half when the sidebar scrolls to the current folder.

側邊欄和首頁的資料夾選單現在一致：最愛（方塊、清單列與首頁卡片）、樹狀中的資料夾、磁碟機和網路位置都有相同的項目和順序，每個資料夾都有「在終端機開啟」、「在 Windows 檔案總管中開啟」、「複製路徑」和「內容」。這些選單的外觀也和檔案清單的選單相同：每列有圖示、右側顯示快速鍵（「在新分頁開啟」顯示 Ctrl+按一下），群組之間有分隔線。磁碟機名稱過長被截斷時會保留磁碟機代號，可用空間有工具提示，「加入最愛」的位置不再被截斷，側邊欄捲到目前資料夾時也不再把方塊切成一半。

侧边栏和主页的文件夹菜单现在一致：收藏夹（磁贴、列表行和主页卡片）、树中的文件夹、驱动器和网络位置都有相同的项目和顺序，每个文件夹都有“在终端中打开”、“在 Windows 文件资源管理器中打开”、“复制路径”和“属性”。这些菜单的外观也和文件列表的菜单相同：每行有图标、右侧显示快捷键（“在新标签页中打开”显示 Ctrl+单击），分组之间有分隔线。驱动器名称过长被截断时会保留驱动器号，可用空间有工具提示，“添加到收藏夹”的位置不再被截断，侧边栏滚动到当前文件夹时也不再把磁贴切成一半。
