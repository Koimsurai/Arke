Pinned commands from third-party menu extensions (such as 7-Zip) show as soon as the menu opens, where they showed for the same kind of item before, instead of waiting for the extension to load. One the extension doesn't add this time goes away once it answers. Pinned commands in a cascading menu made in the registry (as context menu managers make them) no longer wait for the whole Windows menu either: they show right away and run on their own. (#278)
