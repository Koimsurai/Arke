Copies and moves, and Space, can go to any program you name in Settings (an external copy program and a preview program, each a command line with placeholders such as `{sources}`, `{dest}` and `{file}`). They replace the TeraCopy and QuickLook switches, which are converted automatically. "Open with" no longer lists VS Code, Zed and Cursor on its own; add any program there yourself
