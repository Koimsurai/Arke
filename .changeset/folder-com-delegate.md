With "Open folders in Arke" on, folders opened from other programs reach the running Arke directly instead of starting it again, so "Open file location" also works in programs that block starting other programs, like WPS Office (#340)

<!-- zh-TW -->
開啟「用 Arke 開啟資料夾」時，從其他程式開啟的資料夾會直接交給執行中的 Arke，不再另外啟動，所以在會擋下啟動其他程式的軟體（例如 WPS Office）裡按「開啟檔案位置」也能正常開啟 (#340)
