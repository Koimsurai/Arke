Screen readers can use more of Arke: menus, dropdowns and expandable cards open with Enter (sort, view options, the path bar's folder lists, every setting with a list, "More options"), the Menu key opens the context menu, settings read their descriptions and have headings, the context menu settings and shortcut keys are named, and Properties reads its details (#322)
