A setup guide on first run: pick the file manager you're coming from (File Explorer, Total/Double Commander, Directory Opus/XYplorer or Finder) to set Arke up the same way, choose the look, decide whether Arke opens your folders, and bring in your Quick access pins. It opens again from Settings › About and the command palette
