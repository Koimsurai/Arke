# Changelog

## 0.7.1 (2026-11-19)

### Fixes

- Dropdowns in Settings open right under their button again, as wide as it, instead of a button's height lower, and open on the right monitor when the button sits across two monitors. A search filter's menu lines up with its button, and clicking anywhere on that button closes it. The › folder menus in the address bar open under the bar, or above it near the bottom of the screen. Menus and dropdowns opened with the mouse only highlight the option under the pointer; the arrow keys still start from the current one.
- A file could get stuck to the pointer after opening it, when the program it opened in took the mouse button's release, and every click afterwards moved it. A drag now ends as soon as the button is no longer down, and Esc always cancels it.
- Pasting files copied in a Remote Desktop session, an Outlook attachment or a file inside a zip folder now works instead of saying the clipboard has no files. (#221)
- The preview pane now scrolls sideways for wide spreadsheets and CSV or TSV files, with Shift+wheel, a sideways swipe or a scrollbar along the bottom, while the normal wheel still scrolls up and down.
- Files whose type has its own icon, such as AutoHotkey scripts, no longer show up with a tiny dot instead of the icon.
- The release notes shown before updating now use the interface language, as What's new does after the update.

## 0.7.0 (2026-11-19)

### Features

- "Show more options" on a folder's empty space now lists "Give access to" with its items, as File Explorer does, and no longer waits about 1.5 seconds for it. Windows submenus that fill only when opened are kept and filled when you open them. (#129)
- Files dragged in from programs that don't keep them on disk, such as Outlook attachments and messages, images from a browser, or files inside a zip folder, are now saved into the folder they are dropped on, with progress and Cancel in the operation center. (#206)
- Network shares in This PC search are much faster to index and to search: folders are listed several at once in large batches, a daily rewalk lists again only the folders that may have changed, and searching names or file contents below an indexed share takes the files from the index instead of walking the share. Results show up while the first walk is still running. A NAS's snapshots are skipped wherever they show up, and a share opened both as a mapped drive and as `\\server\share` is indexed once.
- Emptying the Recycle Bin and deleting items from it permanently now run as Arke's own operation, with no Windows dialogs: progress and Cancel in a toast and the operation center, and items that can't be deleted are named while the rest still go. Items Windows reported as "Item Not Found" (names ending in a period, data already gone) are now removed.
- A pinned tab keeps its folder: opening another folder from it (a subfolder, the address bar, the sidebar) opens a new tab next to it instead, and Back from that tab returns to the pinned one
- Opening a folder in a new tab switches to the tab already showing it instead of opening a second one; "One tab per folder" in Settings turns this off, and Duplicate tab still makes a copy
- A tab's right-click menu can pin its folder to the sidebar, or unpin it when it's already there
- A setting for what Ctrl+T does: the Go to folder box, a new tab with Home, or a new tab on the current folder (#90)
- Right-click the Back or Forward button to list the folders behind or ahead, and pick one to go there in a single step (#152)
- Mapped network drives, recent network places and saved remote locations can be renamed: right-click one in the sidebar or on Home and choose Rename (or press F2 while it is open). The name is kept in Arke only, so Windows' own drive label is never changed, and it shows in the sidebar, Home, the path bar, tab and window titles and the search scope. Leave the name empty to get the default one back.
- Text boxes now have a right-click menu with Undo, Cut, Copy, Paste, Delete and Select all, in the rename box and while editing the address. Ctrl+Z undoes typing in a text box.
- Single window mode, on by default: folders from other apps, Win+E and starting Arke again open as a tab in the window you used last ("Open in new window" still opens one). Last tabs now remembers every open window, not only the last one closed, and brings them all back.
- The path bar now fills the title row up to the search box: click its empty part to type a path, drag it to move the window, or double-click it to maximize. The search box grows with long text instead of cutting it off, and with the preview pane open, the gap before it lines up with the preview's divider. (#120)
- Updates now download quietly in the background and install the next time Arke restarts: when you quit it, when Windows restarts, or after half an hour in the background with no window open. Instead of a pop-up, the Settings entry in the sidebar shows "Restart to update"; nothing installs while files are being copied, and nothing downloads on a metered connection.
- Add an interface scale (80% to 150%) in Settings under Appearance, and let you resize the sidebar by dragging its right edge (double-click the edge to reset). (#204)
- Ctrl+Shift+P opens a command palette: search any Arke command by name, see its shortcut, and press Enter to run it (typing > in the Ctrl+T box does the same). Settings has a new Keyboard shortcuts page where you can record your own key for a command, swap it with a command that already uses it, and reset one or all.
- Menus now open in windows of their own, like Windows menus: context menus and their submenus, the tab, sidebar and history menus, the edit menu of text boxes, the address bar's folder menu, the Recycle Bin menu and the dropdowns in Settings. Near the edge of the window they are no longer squeezed and can reach past it up to the edge of the screen, and a submenu that doesn't fit on the right opens left of its own menu instead of jumping past all open menus.
- Properties is now Arke's own wide window (Alt+Enter, or Properties in the menus): a picture or icon with quick actions on top, and two columns of cards for the general facts, times, attributes and security (unblock, SHA-256 on demand), and for folders, drives and several items a bar showing where the space goes. Narrow windows fall back to one column. Everything applies at once, and a button opens Windows' own Properties for the rest.
- Drag a tab out of the tab list or the tab bar to open it in a new window where you drop it, with its split view and back/forward history; drop it on another Arke window to move it there. This works with single window mode on too.
- Drag files and folders onto a tab, in the sidebar or the tab bar: the tab comes forward after a short hover, and dropping on it moves or copies them into its folder, with the same keys and drop label as dropping on a folder. (#32)
- Folders now go in the sidebar's favorites: "Add to favorites" in a folder's or a tab's right-click menu (the tiles first, then the list below), or drag a tab, or a folder from Arke or File Explorer, onto the tiles or the list, where a mark shows where it goes. The list below the tiles is now called Favorites, and "Pin" is only for tabs.
- New top bar: the search box sits centered in the title row and searches the active pane, and each pane has its own row with Up, its path bar, its filter and its view buttons. Split view keeps a separate filter per side, shown on that side as a solid chip, and in a narrow pane the selection's buttons fold into a "⋯" menu. With tabs on top, the title row stays on top and the tabs go under it, as in VS Code. (#216)

### Fixes

- The active split pane is marked by a thin accent outline instead of a tint, the pane row no longer repeats the filter query, and a narrow search box shows a short placeholder.
- Sorting by Type now follows the type name shown in the column, as in File Explorer, instead of the extension. Types Arke has no name for show the name Windows has for them (such as "AutoCAD Drawing"). Files whose registered icon is the file itself now show it.
- While a video's preview frame loads, the preview pane and Quick Look now show the same pulsing picture placeholder as images, instead of text-like bars.
- The window title now follows the active tab: switching back to a tab no longer leaves the other tab's folder name in the title and taskbar.
- Sorting by size no longer keeps reordering the list while folder sizes are being worked out: rows stay put and the list reorders once, when every size is known.
- Settings no longer go back to the defaults when the settings file is read slowly (such as `%APPDATA%` on a network drive) and a folder was opened meanwhile. Windows on a second screen reopen there instead of on the main screen.
- Opening a saved workspace no longer opens a second copy of a pinned tab when the folder is spelled differently (another letter case or a trailing backslash).
- The "Open folders in Arke" setting now says that it also makes "Show in folder" in other programs (browsers, editors) open Arke. (#215)
- Text boxes now work by word with Ctrl: Ctrl+Left/Right moves, Ctrl+Shift+Left/Right selects, Ctrl+Backspace/Delete erases, and Shift+Home/End selects to either end. In a path each folder name is a word. (#219)
- The outline of the current folder's tile in the sidebar is no longer cut off at the edge. (#220)
- Extracting an archive that breaks off partway no longer leaves a damaged copy of the file it stopped in. On Windows 10 this happened with RAR archives that Windows' own reader can't fully decode; Arke now says so instead. Cancelling an extraction also removes the file it was writing. (#229)
- In Settings › Appearance, interface scale and list density are now two named rows of their card instead of two unnamed dropdowns side by side. (#230)
- With tabs on top, tabs that don't all fit now scroll sideways (with the mouse wheel too) and the active tab is scrolled into view, instead of the last ones being cut off and out of reach.

## 0.6.0 (2026-11-17)

### Features

Resting the pointer on the column opens the full sidebar over the content until you move away; right click the column to turn that off. Arke remembers which way you left it. (#91) (#122)
- Click the name of the selected item once more (not a double-click) to rename it, like File Explorer. (#89)
- Videos show a frame as their thumbnail in the icon views, the same picture File Explorer shows (from Windows, so formats work as they do there). It is made in a separate background process, so a damaged video or a misbehaving codec can't slow down or crash Arke. (#36)
- Thumbnails are kept small and compressed in memory and on disk, so a folder of pictures you've seen before fills at once, even after restarting Arke, and scrolling back never blinks. Big folders use far less memory: scrolling through 3,000 pictures now takes about half of what it did. Settings › Files and folders shows the cache's size next to Show thumbnails, with a button to clear it. (#95)
- The preview pane shows a file's name, type and dates in full, wrapping them in a narrow pane instead of cutting them off, and also lists its size and creation date. In Quick Look (Space), a name too long for the title bar shows in full on hover.

On a PDF or presentation the wheel turns the pages, scrolling a zoomed-in page to its end first. Images still zoom with the wheel.
- With QuickLook installed, Settings offers "Space opens QuickLook" next to the preview pane switch: Space then previews the item in QuickLook instead of Arke's quick look, and Space again closes it.
- Columns view columns can be resized: drag the divider on a column's right edge, or double-click it to fit the column to its longest name. The widths are remembered for every folder, and names cut off by a narrow column show in full on hover
- The preview pane scrolls through every page of a PDF and lists every slide of a PowerPoint file, not just the first
- In a split tab, the context menu of files and folders has "Copy to other pane" (Alt+C) and "Move to other pane" (Alt+M).

### Fixes

- The report text in Report a problem scrolls with the mouse wheel before the page does, and shows a scrollbar
- Details columns fit beside the preview pane again: the Name column narrows to make room for the other columns, so the last column is no longer cut off at the preview pane's edge
- Dragging files onto a window that sits on top of Arke, such as a launcher toolbar or an always-on-top window, now drops them there instead of moving them into the folder underneath in Arke. (#128)
- Searching a network location no longer walks a NAS's snapshot, recycle bin and thumbnail folders (such as Synology's `#snapshot`, `#recycle` and `@eaDir`), and stops at 2 million items. On a share with snapshots, indexing could run for hours, keeping a CPU core busy and Arke's memory growing.
- Arke stays quiet while nothing changes: an idle, minimized or tray-only Arke no longer redraws on every display refresh (it used to wake up more than a thousand times a second). With no window open it also frees its thumbnail memory and runs at background priority, and the progress ring of file operations costs less to draw.
- Sending thousands of loose files to the Recycle Bin at once is much faster, and Cancel now stops it.
- Rebuilding the search index also waits while Windows Energy Saver is on, including when plugged in, and follows it turning on and off.
- Thumbnails of large photos use far less memory: JPEGs are decoded at a reduced size, and big images are decoded one at a time.
- The helper process behind More options no longer wakes up 33 times a second while idle.
- Searching this PC no longer indexes a subst drive, or a second letter for the same drive, a second time.
- When many files change, the search index folds the changes in instead of reading the whole drive again, which on a busy drive used to take tens of seconds about every hour. The log now says why each full rebuild happens.
- The search index saves its progress less often, cutting its disk writes on busy drives to about a quarter.
- The background index service waits for changes instead of checking every 300 ms, and runs in efficiency mode with low memory priority.
- Typing in this PC search no longer starts a thread per CPU core for every keystroke, and a query that was typed over stops instead of running to the end.
- Folders that get thousands of new files at once, such as an extracted archive, now show them instead of keeping the old list
- Folder sizes use far less CPU: only folders on screen are measured, recent results are reused when you go back or into a subfolder, and at most two folders are measured at once
- Open tabs no longer wake up 20 times a second each to watch their folder
- Large folders take many changes at once without listing the whole folder again
- Settings › Search no longer has the change journal size: Windows can make a drive's journal larger but never smaller again, and Arke doesn't need a larger one. If you made one larger, docs/change-journal.md explains how to go back. (#150)
- In Settings › Search, the mouse wheel now scrolls the page while the pointer is over the dimmed sections shown when whole-PC search is off.
- Search no longer finds files from a folder that was deleted and made again, or replaced by another folder of the same name (as build tools and app updaters do).
- Search no longer misses changes when its folder watch overflows soon after a rebuild, or when the search service loses its place while the index is being updated: the rebuild now follows instead of being skipped. When the change journal keeps getting deleted (some cleanup tools do this), rebuilds are spaced further apart.
- When the search service was installed by an earlier version of Arke, Settings › Search offers to update it: Arke updates don't replace the service's own copy, so it kept running the old version.
- In a short window, the preview pane gives the preview less height so the file's name and details below it stay inside the window instead of being cut off at the bottom.
- Going back up to a folder sorted by size keeps the folder you came from in its place while its size is computed again, instead of moving it to the end. (#161)
- Updating the search service from Settings no longer fails with "file in use" while the service is running.
- The sidebar slides when it collapses or expands with Ctrl+B, and a row cut off at the bottom of the sidebar's places or tabs is dimmed so it reads as more below.
- Polish for the new 0.6 features: the sidebar opened over the content slides in and fades out, and stays open when the pointer comes straight back; a flick into the top-right corner of a maximized window lights Close up; videos show a frame in the preview pane and Quick Look; in a short window a PDF's pages fit the preview and its details get a scrollbar; PDF pages still rendering pulse; the column view's parent column no longer squeezes the current one out in a smaller window; and the "more items" line follows Quick Look's zoom.
- Moving items to the Recycle Bin no longer shows more items processed than were selected. When a folder had a file in use or Windows asked about deleting it permanently, the count could go past the selection.
- Opening many vertical tabs no longer squeezes the sidebar's places (This PC, Network): the tab list gives way first, down to three tabs, and scrolls. Only when the window is too short for that do the places shrink too.
- Collapsing and expanding the sidebar crossfades between the full sidebar and the column of icons while it slides, instead of switching from one to the other at the end.

- An archive's preview lists each folder right before its contents, folders before files and names in order, like File Explorer; folders an archive only names in paths are listed too.
- When the window is maximized, the top-right corner of the screen and the top edge above the window buttons now hit those buttons, so flicking the mouse into the corner and clicking closes Arke, as in other Windows apps.

## 0.1.0

First public release.

- **Never freezes.** Listing, sorting, thumbnails, folder sizes, search and file operations run
  off the UI thread, so slow network shares and folders with 100,000 files stay smooth.
- **Search everything as you type**: this folder, its subfolders or the whole computer, from an
  NTFS index built in seconds (optional background service), with type, size and date filters
  and search inside files, including PDF and Office documents.
- **Many folders at once**: vertical tabs you can pin and save as workspaces, split view with
  synchronized browsing and folder compare, spring-loaded folders and a shelf.
- **Views and previews**: details (with folders that expand in place), icons at any size and
  columns; a resizable preview pane and Quick Look for images, PDF, Word, Excel, PowerPoint,
  code, Markdown and archives.
- **Files**: Windows' own copy engine with undo and redo, a per-drive queue, batch rename and
  archives (zip, 7z, tar, RAR). A delete that fails names the file and the program holding it,
  with Retry, and the rest of the selection still goes.
- **Places**: network shares that fail fast, OneDrive and other cloud folders with sync status.
- **Clean to remove**: an optional Start menu shortcut, and Settings › About › Remove Arke from
  this PC (or `arke --uninstall`) takes away the search service, shortcuts, saved passwords, the
  jump list, Arke's data and the exe.
- **Report a problem** hides your account, profile folder, computer and server names (and by
  default file names), and shows the exact text before it is copied or saved.
- Light and dark themes, accent colors, screen reader support, English, Simplified and
  Traditional Chinese, x64 and ARM64. No telemetry, one exe, and apart from the optional search
  service no registry writes unless you turn on "Open folders in Arke".

Experimental in this release (tested with automated tests and local test servers, not yet widely
in real use; feedback in issues is welcome):

- Opening folders in Arke instead of File Explorer (Settings › Startup)
