## 0.1.0

First public release.

- **Never freezes.** Listing, sorting, thumbnails, folder sizes, search and file operations run
  off the UI thread, so slow network shares and folders with 100,000 files stay smooth.
- **Search everything as you type**: this folder, its subfolders or the whole computer, from an
  NTFS index built in seconds (optional background service), with type, size and date filters
  and search inside files, including PDF and Office documents.
- **Many folders at once**: vertical tabs you can pin and save as workspaces, split view with
  synchronized browsing and folder compare, spring-loaded folders and a shelf.
- **Views and previews**: details (with folders that expand in place), icons at any size and
  columns; a resizable preview pane and Quick Look for images, PDF, Word, Excel, PowerPoint,
  code, Markdown and archives.
- **Files**: Windows' own copy engine with undo and redo, a per-drive queue, batch rename and
  archives (zip, 7z, tar, RAR). A delete that fails names the file and the program holding it,
  with Retry, and the rest of the selection still goes.
- **Places**: network shares that fail fast, OneDrive and other cloud folders with sync status.
- **Clean to remove**: an optional Start menu shortcut, and Settings › About › Remove Arke from
  this PC (or `arke --uninstall`) takes away the search service, shortcuts, saved passwords, the
  jump list, Arke's data and the exe.
- **Report a problem** hides your account, profile folder, computer and server names (and by
  default file names), and shows the exact text before it is copied or saved.
- Light and dark themes, accent colors, screen reader support, English, Simplified and
  Traditional Chinese, x64 and ARM64. No telemetry, one exe, and apart from the optional search
  service no registry writes unless you turn on "Open folders in Arke".

Experimental in this release (tested with automated tests and local test servers, not yet widely
in real use; feedback in issues is welcome):

- Opening folders in Arke instead of File Explorer (Settings › Startup)
- SFTP and WebDAV locations
- "Syncing" and "not synced" cloud badges
- Handing copies and moves to TeraCopy
- Releasing a drive when another app ejects it
- The ARM64 build (cross-compiled, not yet tested on real ARM hardware)
