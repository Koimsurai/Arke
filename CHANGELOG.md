# Changelog

Generated by `cargo xtask version` from the files in `.changeset/`.

## 0.6.1 (2026-11-18)

### Fixes

- A command pinned to the top of the context menu from "Show more options" now shows right away instead of waiting for every extension in the Windows menu: its extension is read on its own. The first menu after pinning learns which extension that is. How long each extension takes is written to the log, to find a slow one. (#129)
- The background process that reads the Windows context menu is replaced after 100 menus, so threads that some Windows extensions leave behind on every menu (Work Folders) no longer pile up while Arke runs for days.
- Mapped network drives that Windows hadn't reconnected after a restart open again, like in File Explorer
- With New windows open to set to Last tabs, a window opened while Arke is already open starts on Home instead of the user folder (#178)
- Building the search index takes less memory at its peak, and memory held for changes is given back once they're folded into the index
- Checking for updates works where many people share one address (school, office, café): when GitHub's limit for its API is used up, Arke reads the releases page's feed instead (#183)
- Commands that apps add only to the menu of a folder's empty space, such as Everything's "Search Everything...", run again instead of saying no app is associated (#184)

## 0.6.0 (2026-11-17)

### Features

- The sidebar collapses to a narrow column of icons with Ctrl+B or the button at its top: Home, quick access, the pinned folders, the Recycle Bin and the Shelf, the drives (as C:, D:...), back and forward, the vertical tabs and Settings stay one click away, with their names on hover. Resting the pointer on the column opens the full sidebar over the content until you move away; right click the column to turn that off. Arke remembers which way you left it. (#91) (#122)
- Click the name of the selected item once more (not a double-click) to rename it, like File Explorer. (#89)
- Videos show a frame as their thumbnail in the icon views, the same picture File Explorer shows (from Windows, so formats work as they do there). It is made in a separate background process, so a damaged video or a misbehaving codec can't slow down or crash Arke. (#36)
- Thumbnails are kept small and compressed in memory and on disk, so a folder of pictures you've seen before fills at once, even after restarting Arke, and scrolling back never blinks. Big folders use far less memory: scrolling through 3,000 pictures now takes about half of what it did. Settings › Files and folders shows the cache's size next to Show thumbnails, with a button to clear it. (#95)
- The preview pane shows a file's name, type and dates in full, wrapping them in a narrow pane instead of cutting them off, and also lists its size and creation date. In Quick Look (Space), a name too long for the title bar shows in full on hover.
- In Quick Look (Space), Ctrl+wheel (or Ctrl+= and Ctrl+-, Ctrl+0 for 100%) makes text, Markdown, Word documents, sheets, slides, archive and folder listings and PDF pages larger or smaller; the zoom stays while you move between items. On a PDF or presentation the wheel turns the pages, scrolling a zoomed-in page to its end first. Images still zoom with the wheel.
- With QuickLook installed, Settings offers "Space opens QuickLook" next to the preview pane switch: Space then previews the item in QuickLook instead of Arke's quick look, and Space again closes it.
- Columns view columns can be resized: drag the divider on a column's right edge, or double-click it to fit the column to its longest name. The widths are remembered for every folder, and names cut off by a narrow column show in full on hover
- The preview pane scrolls through every page of a PDF and lists every slide of a PowerPoint file, not just the first
- In a split tab, the context menu of files and folders has "Copy to other pane" (Alt+C) and "Move to other pane" (Alt+M).

### Fixes

- The report text in Report a problem scrolls with the mouse wheel before the page does, and shows a scrollbar
- Details columns fit beside the preview pane again: the Name column narrows to make room for the other columns, so the last column is no longer cut off at the preview pane's edge
- Dragging files onto a window that sits on top of Arke, such as a launcher toolbar or an always-on-top window, now drops them there instead of moving them into the folder underneath in Arke. (#128)
- Searching a network location no longer walks a NAS's snapshot, recycle bin and thumbnail folders (such as Synology's `#snapshot`, `#recycle` and `@eaDir`), and stops at 2 million items. On a share with snapshots, indexing could run for hours, keeping a CPU core busy and Arke's memory growing.
- Arke stays quiet while nothing changes: an idle, minimized or tray-only Arke no longer redraws on every display refresh (it used to wake up more than a thousand times a second). With no window open it also frees its thumbnail memory and runs at background priority, and the progress ring of file operations costs less to draw.
- Sending thousands of loose files to the Recycle Bin at once is much faster, and Cancel now stops it.
- Rebuilding the search index also waits while Windows Energy Saver is on, including when plugged in, and follows it turning on and off.
- Thumbnails of large photos use far less memory: JPEGs are decoded at a reduced size, and big images are decoded one at a time.
- The helper process behind More options no longer wakes up 33 times a second while idle.
- Searching this PC no longer indexes a subst drive, or a second letter for the same drive, a second time.
- When many files change, the search index folds the changes in instead of reading the whole drive again, which on a busy drive used to take tens of seconds about every hour. The log now says why each full rebuild happens.
- The search index saves its progress less often, cutting its disk writes on busy drives to about a quarter.
- The background index service waits for changes instead of checking every 300 ms, and runs in efficiency mode with low memory priority.
- Typing in this PC search no longer starts a thread per CPU core for every keystroke, and a query that was typed over stops instead of running to the end.
- Folders that get thousands of new files at once, such as an extracted archive, now show them instead of keeping the old list
- Folder sizes use far less CPU: only folders on screen are measured, recent results are reused when you go back or into a subfolder, and at most two folders are measured at once
- Open tabs no longer wake up 20 times a second each to watch their folder
- Large folders take many changes at once without listing the whole folder again
- Settings › Search no longer has the change journal size: Windows can make a drive's journal larger but never smaller again, and Arke doesn't need a larger one. If you made one larger, docs/change-journal.md explains how to go back. (#150)
- In Settings › Search, the mouse wheel now scrolls the page while the pointer is over the dimmed sections shown when whole-PC search is off.
- Search no longer finds files from a folder that was deleted and made again, or replaced by another folder of the same name (as build tools and app updaters do).
- Search no longer misses changes when its folder watch overflows soon after a rebuild, or when the search service loses its place while the index is being updated: the rebuild now follows instead of being skipped. When the change journal keeps getting deleted (some cleanup tools do this), rebuilds are spaced further apart.
- When the search service was installed by an earlier version of Arke, Settings › Search offers to update it: Arke updates don't replace the service's own copy, so it kept running the old version.
- In a short window, the preview pane gives the preview less height so the file's name and details below it stay inside the window instead of being cut off at the bottom.
- Going back up to a folder sorted by size keeps the folder you came from in its place while its size is computed again, instead of moving it to the end. (#161)
- Updating the search service from Settings no longer fails with "file in use" while the service is running.
- The sidebar slides when it collapses or expands with Ctrl+B, and a row cut off at the bottom of the sidebar's places or tabs is dimmed so it reads as more below.
- Polish for the new 0.6 features: the sidebar opened over the content slides in and fades out, and stays open when the pointer comes straight back; a flick into the top-right corner of a maximized window lights Close up; videos show a frame in the preview pane and Quick Look; in a short window a PDF's pages fit the preview and its details get a scrollbar; PDF pages still rendering pulse; the column view's parent column no longer squeezes the current one out in a smaller window; and the "more items" line follows Quick Look's zoom.
- Moving items to the Recycle Bin no longer shows more items processed than were selected. When a folder had a file in use or Windows asked about deleting it permanently, the count could go past the selection.
- Opening many vertical tabs no longer squeezes the sidebar's places (This PC, Network): the tab list gives way first, down to three tabs, and scrolls. Only when the window is too short for that do the places shrink too.
- Collapsing and expanding the sidebar crossfades between the full sidebar and the column of icons while it slides, instead of switching from one to the other at the end.
- Floppy disk drives (A:, and USB floppy drives) are listed under This PC and on Home like File Explorer does, with or without a disk in them, and are never read just to show the list. Removable drives left out for having no disk are now noted in the log. (#125)
- Files dragged in from 7-Zip, NanaZip and other archive managers arrive: Arke asks the source for them again when they are dropped, which is when such an app extracts them, and takes them before it deletes its temp copies. (#168)
- An archive's preview lists each folder right before its contents, folders before files and names in order, like File Explorer; folders an archive only names in paths are listed too.
- When the window is maximized, the top-right corner of the screen and the top edge above the window buttons now hit those buttons, so flicking the mouse into the corner and clicking closes Arke, as in other Windows apps.
- Context menus and submenus open faster: a short fade in place instead of sliding in.

## 0.5.2 (2026-11-16)

### Fixes

- Uses much less memory on integrated graphics: a maximized window no longer keeps about 70 MB of drawing buffers it rarely needs.
- This PC lists cloud folders the way File Explorer's navigation pane does: a provider that registers a sync root for every synced folder (like Nutstore) shows only the folder it pins there. (#93)
- Closing Settings, Home or another page that opened in its own tab goes back to the tab it was opened from, not to the tab next to it.
- A filter menu in the search panel (Type, Size, Date modified) now closes when you click anywhere outside it, including blank space in the panel.
- Files dragged out of Arke now carry the same item list as File Explorer's drags, so apps that read only that (such as shortcuts on launcher toolbars) receive them. (#109)
- A context menu or submenu (such as More options) taller than the window is no longer cut off: it stays inside the window and scrolls, and the arrow keys scroll to the highlighted item. (#114)
- Report a problem opens GitHub's bug form with your version, Windows build, settings and the latest log lines already in it, so there's nothing to paste. A new Show log file button opens the log itself.
- Arke now always opens where Settings › Startup says (Home, last location or last tabs). Started with no folder, it could stay on the user folder when its settings were read faster or slower than usual. (#116)

In Quick Look, Markdown and Word documents sit on a page. ### Fixes

- Clicking inside the rename box now moves the caret instead of ending the rename, and double-clicking there no longer opens the file. (#69)
- Text and CSV previews no longer come up empty when the file breaks lines with a lone CR (like old Mac Excel exports), or has form feeds, vertical tabs or NEL characters in it. Those now start a new line.
- Declining Windows' approval prompt while updating an Arke installed for all users no longer closes Arke. It stays open, the update notice says the update didn't happen and offers Try again, and Settings › About shows "Not updated".
- Win+E now opens Arke the same way starting it does, following "New windows open to" (your last tabs when it is set to them), instead of always opening Home. (#73)
- Fixed a rare crash: if the text in a box changed while you were selecting in it with the mouse (for example Tab completing the path bar during a drag), the next key you pressed could close Arke.
- Markdown previews no longer come up empty for files saved with lone CR line breaks, and a paragraph with form feeds in it no longer disappears.
- Search across the PC lists files added since indexing in a fixed order when they match equally well, so the same results stay on top.
- In a short window, the vertical tab list no longer disappears below the places in the sidebar: both parts scroll on their own and at least three tabs stay in view.
- Back from a folder opened from Home now returns to Home, like a browser, and back on Home shows the folder it was opened from. (#70)
- Removing one copy of Arke while another is installed or running (say a portable copy next to an installed one) now removes only that copy. The search service, settings, saved passwords, index and the other copy's folder handling stay, and the other copy keeps running.

## 0.1.0

First public release.

- **Never freezes.** Listing, sorting, thumbnails, folder sizes, search and file operations run
  off the UI thread, so slow network shares and folders with 100,000 files stay smooth.
- **Search everything as you type**: this folder, its subfolders or the whole computer, from an
  NTFS index built in seconds (optional background service), with type, size and date filters
  and search inside files, including PDF and Office documents.
- **Many folders at once**: vertical tabs you can pin and save as workspaces, split view with
  synchronized browsing and folder compare, spring-loaded folders and a shelf.
- **Views and previews**: details (with folders that expand in place), icons at any size and
  columns; a resizable preview pane and Quick Look for images, PDF, Word, Excel, PowerPoint,
  code, Markdown and archives.
- **Files**: Windows' own copy engine with undo and redo, a per-drive queue, batch rename and
  archives (zip, 7z, tar, RAR). A delete that fails names the file and the program holding it,
  with Retry, and the rest of the selection still goes.
- **Places**: network shares that fail fast, OneDrive and other cloud folders with sync status.
- **Clean to remove**: an optional Start menu shortcut, and Settings › About › Remove Arke from
  this PC (or `arke --uninstall`) takes away the search service, shortcuts, saved passwords, the
  jump list, Arke's data and the exe.
- **Report a problem** hides your account, profile folder, computer and server names (and by
  default file names), and shows the exact text before it is copied or saved.
- Light and dark themes, accent colors, screen reader support, English, Simplified and
  Traditional Chinese, x64 and ARM64. No telemetry, one exe, and apart from the optional search
  service no registry writes unless you turn on "Open folders in Arke".

Experimental in this release (tested with automated tests and local test servers, not yet widely
in real use; feedback in issues is welcome):

- Opening folders in Arke instead of File Explorer (Settings › Startup)
- SFTP and WebDAV locations
- "Syncing" and "not synced" cloud badges
- Handing copies and moves to TeraCopy
- Releasing a drive when another app ejects it
- The ARM64 build (cross-compiled, not yet tested on real ARM hardware)
