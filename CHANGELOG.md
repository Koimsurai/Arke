## 0.9.2 (2026-11-25)

### Fixes

- Cloud drive folders whose sync app only adds online-only files once a folder is opened in File Explorer (like WPS Cloud) now show those files in Arke too, without opening the folder in File Explorer first (#319)
- With "Open folders in Arke" on, folders opened from other programs reach the running Arke directly instead of starting it again, so "Open file location" also works in programs that block starting other programs, like WPS Office (#340)
- The Network section of the sidebar can be hidden, like Favorites and This PC: right-click its heading, and right-click the empty space of the sidebar to show it again. Mapped network drives then show under This PC, as in File Explorer (#387)
- The progress note at the bottom shows scissors while moving files, as the operation center does, instead of the copy icon (#403)
- Folders reached through a junction, such as Scoop's `current`, open in an Arke the installer started after installing or updating, and in the terminals it opens, instead of failing with error 448. Files whose app was installed with Scoop open in that app instead of asking which app to use (#406, #392)
- Searching subfolders or This PC lists only the names that contain the text as typed; names that merely share some letters wait under a closed "Similar results" row, and show right away when nothing matches exactly. Start with `'` for exact matches only (#396)
- The line between the places and the tabs in the sidebar always shows, so it can be found and dragged; clicking it without dragging no longer fixes the places' height
- With "Open folders in Arke" on, a folder another program opens with `explorer.exe <folder>` (or `/select,` a file, or the Recycle Bin) opens in Arke without File Explorer's window showing first (#285)
- Selecting text by dragging in a text field keeps extending the selection when the pointer leaves the field (#410)

- Grouped lists no longer show section headers in the wrong places after a file is renamed, such as a download finishing (#335)
- Pressing Alt+Tab while dragging files no longer drops the drag: the files go on as a Windows drag, so they can be dropped in the window switched to, as in File Explorer (#326)
- A file renamed only in case, or reported by its short name, no longer shows twice until F5; search finds it under its new name too (#310)
- Search this PC uses less memory over a long session: temporary files made and deleted since the index was built no longer leave records behind. A new folder deleted with its contents no longer leaves those files in search results until the next index update. Tabs that never search no longer keep a search thread
- PDF previews keep at most 96 MB of rendered pages across all tabs, instead of up to 12 pages in each tab
- The preview pane no longer keeps every picture it has shown in video memory, which grew by about 7 MB per picture until Arke was restarted

- The menu on a folder's empty space has Properties, which opens Arke's window for that folder (like Alt+Enter with nothing selected) instead of File Explorer's dialog from "Show more options"
- Fonts named only in another language (some Chinese fonts) show in the font list instead of being left out (#343)
- A failed update download says why (timed out, name not resolved, can't connect) instead of showing an empty reason (#343)
- Updating or restarting the search service no longer rebuilds the whole index: once the service is back, search picks up changes from where it left off, including those made meanwhile (#343)
- The Recycle Bin page shows what was deleted from exFAT and FAT drives (most portable drives), and can delete it for good; it only listed NTFS drives' items (#330)

- Removing Arke installed with Scoop hands folders back to File Explorer: Scoop runs the removal from the version folder while the registration points through its `current` link, so the two were taken for different copies and folders kept opening the deleted Arke

- Removing Arke keeps its settings folder when handing folders back to File Explorer failed, even when told to delete the settings: the backup of what to put back is in it, so running the removal again can finish instead of leaving folders pointing at the removed Arke (#360)

## 0.8.0 (2026-11-22)

### Features

- Double-clicking a folder in the sidebar's tree expands or collapses it, as in File Explorer; the first click still opens it. (#242)
- The folder tree under This PC follows the folder you're in: it opens down to it and marks it, scrolling it into view if needed, and closes again what it opened once you go elsewhere. Folders you expanded yourself stay open. (#241)
- Favorite tiles move like app icons on a phone: a dragged tile lifts under the pointer, the others slide aside to make room, and it settles into its new place when you let go. To remove a favorite, drag it (a tile or an entry of the list) out of the sidebar and let go, like an app off the macOS Dock; a trash badge shows it will go, and the toast that follows has Undo.
- A favorite whose name doesn't fit on a tile is listed as a row under the tiles instead of being cut off. It keeps its place among your favorites, so it goes back to its tile when the name fits again (a wider sidebar or a shorter name). (#174)
- Favorites can be renamed: right-click a tile or a row in the favorites › Rename. The name shows only for the favorite (the folder keeps its own name everywhere else); an empty name brings the folder's name back. (#259)
- Removing the Recycle Bin from the sidebar now says it's on the Home page, next to the drives. (#31)
- Favorites, This PC and Network in the sidebar can each be collapsed by clicking their heading; Arke remembers which ones are collapsed.
- Home shows your favorite tiles, the same ones in the same order and with the same names as at the top of the sidebar, instead of a fixed set of folders. (#173)
- Icon views show the first page of a PDF as its thumbnail. (#33)
- The preview pane and Quick Look draw SVG images, and show what a plain .gz file holds: the name and size of the file inside, and its text when it is small. (#174)
- Drag the boundary between the preview and its details in the preview pane to resize it; double-click it to reset. (#174)
- You can now sign in to a WebDAV server over plain http after allowing it for that one location; Arke warns that the password goes over the network unencrypted. (#252)
- A setting chooses what closing the last tab does: close the window (the default) or show Home in that tab. (#253, #255)
- With "Open items with a single click" on, resting the pointer on an item selects it, as in File Explorer. (#46)
- Home hides its recent files when "Show recently used files" is off in Windows. (#92)
- Launchers and scripts (ALTRun, Listary, AutoHotkey, PowerShell) can read Arke's windows, tabs, folders and selection, open a folder with items selected, and run commands, through one JSON interface: `WM_COPYDATA` to a window of class `ArkeWindow`, or `arke.exe --api`. Commands that change files are not available. See docs/integration.md. (#193)
- Folders pinned to Quick Access in File Explorer now also appear in Arke's favorites. If you had already arranged your favorites, only folders you pin from now on are added. Arke doesn't change Windows' Quick Access. (#45)
- Finished operations no longer pop up a notification; they are listed in the operation center. A progress notification appears only for operations that take more than a couple of seconds. Moving to the Recycle Bin still offers Undo, and failures still show. (#266)
- Icons and thumbnails go up to 256 px with the size slider or Ctrl+mouse wheel, past extra large. (#267)
- Right-clicking with Shift held adds the Windows commands that appear only then (such as Open PowerShell window here) to More options, as in File Explorer. (#272)
- On Home, favorites can be dragged to reorder them (the sidebar follows) and have the same right-click menu as in the sidebar; drives and recent files get right-click menus too. (#173)
- Drives in the sidebar and on Home get a drive menu: copy path, open in Terminal or File Explorer, eject, Format, Disk Cleanup and Properties.
- The collapsed sidebar no longer opens on hover unless turned on (right-click the column, or in Settings); when on, it opens only once the pointer rests still on the column, so heading for a drive or tab and clicking it no longer opens it.
- Arke is now available in Japanese, German, Spanish and Brazilian Portuguese. It follows the Windows display language, or pick one in Settings.

### Fixes

- Deleting on a `subst` drive, or on a drive where the Recycle Bin is turned off, now asks in Arke before deleting permanently, instead of Windows asking behind the window.
- Deleting something too big for the Recycle Bin now asks in Arke whether to delete it permanently, instead of Windows asking behind the window; the rest goes to the bin right away.
- Grouped Details keeps its sections when a folder is expanded in the list; the folder's items stay under it, in its section. (#279)
- Context menus and dropdowns have a smaller, softer shadow, closer to Windows' own menus. (#275)
- Pinned Windows commands that come from the registry (such as Git Bash Here) or from apps like Windows Terminal, VS Code and Zed now show and run as soon as the menu opens, instead of waiting for the whole Windows menu. (#278)
- Dragging favorites in the sidebar: a favorite takes the shape of where it is, a tile over the tiles and a row over the list, and both make room for it as it moves; while it is a tile, the list shows where it can go, and while it is a row, the tiles do. Let go where nothing takes it, it goes back where it was, and Undo after dragging it out puts it back there too. Clicking a favorite no longer scrolls the sidebar down to the folder tree.
- Properties counts a folder's or drive's space much faster: from the search index in one pass when it follows that drive (a whole drive in well under a second), otherwise walking with four threads (about 2.6 times faster on a whole drive).
- When the search index doesn't cover a drive, Properties counts the drive from its file table through the index service, the way WizTree does (C: drops from over a minute to seconds). For a big folder, the file table takes over a walk that has been running as long as reading the table took last time on that drive, and whichever is done first is shown; the other stops at once, so a small folder never waits for the table. On a hard disk the walk hands over to the table instead of both reading at once.
- Extracting a password-protected ZIP says the archive has a password instead of calling it damaged. (#282)
- In text boxes, including renaming, a double-click selects a word and a triple-click selects everything. (#284)
- In Settings, the + and Browse button for adding a program to Open with line up with the text box. (#281)
- The preview pane keeps a folder's or archive's details (type, dates, location) below its contents instead of showing them only until the contents load. (#290)
- Ctrl+click a folder in the sidebar, on Home or in the address bar to open it in a new tab in the background, or Ctrl+Shift+click to switch to it; in the file list, where Ctrl+click selects, Ctrl+double-click does the same. Middle-click also works in the address bar now. (#291)
- A pinned command from an app's own submenu in "Show more options", such as NanaZip's or WinRAR's "Extract here", now shows right away like other pinned commands instead of waiting for the whole Windows menu. (#283)
- With "Open folders in Arke" on, a File Explorer window opened by another program (a launcher opening the Recycle Bin, `explorer.exe <folder>`) is taken over about half a second after it appears, instead of staying on screen for up to two seconds. (#285)
- Sorting by size works out folder sizes from the top of the list down, instead of in a random order where one slow folder could hold up the rest.
- A tab dragged onto another Arke window goes to the window under the pointer, also where windows overlap or screens use different scales; a window covered by another program no longer takes it.
- Properties counts `C:\Users\Default` instead of showing 0, and a count that misses other people's profiles you can't read (a drive, `C:\Users`, someone else's profile) now says "at least". On a spinning disk, folders are counted from the drive's file table in one sweep instead of walking them first (walked only when the table can't count them), and folders the file table can't count are no longer read from it for nothing. "Where the space goes" is there from the moment Properties opens, filled in when the count is done, instead of appearing all at once.
- A damaged PDF can no longer stall or crash Arke while a folder's thumbnails load. Extracting a zip with some password-protected files now fails up front instead of leaving a half-extracted folder. A file named just `.gz` shows a name in the preview, and the preview details show the modified date once instead of twice.
- The menus of folders in the sidebar and on Home now match: favorites (tiles, list rows and Home cards), folders in the tree, drives and network places have the same rows in the same order, with Open in Terminal, Open in Windows File Explorer, Copy path and Properties for every folder. These menus also look like the file list's: an icon on each row, keys on the right (Ctrl+click for "Open in new tab"), and lines between groups. Drive names keep their letter when cut short, a drive's free space has a tooltip, and the "Add to favorites" spot is no longer cut off. Dragging a favorite between the tiles and the list shows where it can go only in the other part, and the spot it will land on stays put as it gets there; the part it left just closes up. Rows of the list slide aside to make room for it, as tiles do, and picking one up with the tiles scrolled out of sight no longer pushes the list down. When the sidebar scrolls to the current folder, it no longer leaves a row of tiles cut in half at the top.
- Working in a folder inside a favorite or a pinned folder, the sidebar stays on the favorite instead of scrolling down to the folder under This PC (#307). A new switch in Settings, under "Tab position" with the other sidebar options, stops This PC from opening to the current folder (#299).
- Names starting with a symbol such as `_` or `(` sort before names starting with a digit, as in File Explorer (#311).
- Pinned commands from third-party menu extensions (such as 7-Zip) show as soon as the menu opens, where they showed for the same kind of item before, instead of waiting for the extension to load. One the extension doesn't add this time goes away once it answers. Pinned commands in a cascading menu made in the registry (as context menu managers make them) no longer wait for the whole Windows menu either: they show right away and run on their own, including ones an earlier version had left to the whole menu. A command learns where it comes from as soon as it is pinned, so it shows quickly from the very next menu. (#278)
- In a narrow window, the column chips in Settings › Sorting and view wrap onto more lines instead of squeezing the card's title to a letter a line (#313).
- Removable drives (USB disks and sticks) show their name, as in File Explorer, instead of "Removable Disk" (#315).
- With tabs in the sidebar, drag the line between the folders and the tabs to give either more room, as with Firefox's vertical tabs; Arke remembers it, and double-clicking the line shares the room by itself again.
- Dragging a favorite between the tiles and the list: it changes shape smoothly, with a little spring, a tile and a row now look alike, a tile taken to the list and brought back to its empty place turns into a tile again, and list rows no longer trade places back and forth under a pointer resting between them.
- The preview no longer draws pictures an SVG points to outside itself when the tag has a namespace prefix; drive format errors are translated; a pinned registry command keeps working beside a cascading menu that has a command of the same name.

## 0.7.0 (2026-11-19)

### Features

- "Show more options" on a folder's empty space now lists "Give access to" with its items, as File Explorer does, and no longer waits about 1.5 seconds for it. Windows submenus that fill only when opened are kept and filled when you open them. (#129)
- Files dragged in from programs that don't keep them on disk, such as Outlook attachments and messages, images from a browser, or files inside a zip folder, are now saved into the folder they are dropped on, with progress and Cancel in the operation center. (#206)
- Network shares in This PC search are much faster to index and to search: folders are listed several at once in large batches, a daily rewalk lists again only the folders that may have changed, and searching names or file contents below an indexed share takes the files from the index instead of walking the share. Results show up while the first walk is still running. A NAS's snapshots are skipped wherever they show up, and a share opened both as a mapped drive and as `\\server\share` is indexed once.
- Emptying the Recycle Bin and deleting items from it permanently now run as Arke's own operation, with no Windows dialogs: progress and Cancel in a toast and the operation center, and items that can't be deleted are named while the rest still go. Items Windows reported as "Item Not Found" (names ending in a period, data already gone) are now removed.
- A pinned tab keeps its folder: opening another folder from it (a subfolder, the address bar, the sidebar) opens a new tab next to it instead, and Back from that tab returns to the pinned one
- Opening a folder in a new tab switches to the tab already showing it instead of opening a second one; "One tab per folder" in Settings turns this off, and Duplicate tab still makes a copy
- A tab's right-click menu can pin its folder to the sidebar, or unpin it when it's already there
- A setting for what Ctrl+T does: the Go to folder box, a new tab with Home, or a new tab on the current folder (#90)
- Right-click the Back or Forward button to list the folders behind or ahead, and pick one to go there in a single step (#152)
- Mapped network drives, recent network places and saved remote locations can be renamed: right-click one in the sidebar or on Home and choose Rename (or press F2 while it is open). The name is kept in Arke only, so Windows' own drive label is never changed, and it shows in the sidebar, Home, the path bar, tab and window titles and the search scope. Leave the name empty to get the default one back.
- Text boxes now have a right-click menu with Undo, Cut, Copy, Paste, Delete and Select all, in the rename box and while editing the address. Ctrl+Z undoes typing in a text box.

## 0.1.0

First public release.

- **Never freezes.** Listing, sorting, thumbnails, folder sizes, search and file operations run
  off the UI thread, so slow network shares and folders with 100,000 files stay smooth.
- **Search everything as you type**: this folder, its subfolders or the whole computer, from an
  NTFS index built in seconds (optional background service), with type, size and date filters
  and search inside files, including PDF and Office documents.
- **Many folders at once**: vertical tabs you can pin and save as workspaces, split view with
  synchronized browsing and folder compare, spring-loaded folders and a shelf.
- **Views and previews**: details (with folders that expand in place), icons at any size and
  columns; a resizable preview pane and Quick Look for images, PDF, Word, Excel, PowerPoint,
  code, Markdown and archives.
- **Files**: Windows' own copy engine with undo and redo, a per-drive queue, batch rename and
  archives (zip, 7z, tar, RAR). A delete that fails names the file and the program holding it,
  with Retry, and the rest of the selection still goes.
- **Places**: network shares that fail fast, OneDrive and other cloud folders with sync status.
- **Clean to remove**: an optional Start menu shortcut, and Settings › About › Remove Arke from
  this PC (or `arke --uninstall`) takes away the search service, shortcuts, saved passwords, the
  jump list, Arke's data and the exe.
- **Report a problem** hides your account, profile folder, computer and server names (and by
  default file names), and shows the exact text before it is copied or saved.
- Light and dark themes, accent colors, screen reader support, English, Simplified and
  Traditional Chinese, x64 and ARM64. No telemetry, one exe, and apart from the optional search
  service no registry writes unless you turn on "Open folders in Arke".

Experimental in this release (tested with automated tests and local test servers, not yet widely
in real use; feedback in issues is welcome):

- Opening folders in Arke instead of File Explorer (Settings › Startup)
- SFTP and WebDAV locations
- "Syncing" and "not synced" cloud badges
- Handing copies and moves to TeraCopy
- Releasing a drive when another app ejects it
- The ARM64 build (cross-compiled, not yet tested on real ARM hardware)
