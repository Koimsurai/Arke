## RAR and compressed tars (no bundled code)

Arke contains no RAR decoder. RAR, `.tar.xz`, `.tar.bz2` and `.tar.zst` are read by the copy of
libarchive that ships with Windows (`System32\archiveint.dll`, or `System32\tar.exe` on older
versions), loaded or run at run time as part of the operating system.

## Files app (MIT), design reference only

The folder handler registration (`Folder\shell\open` / `explore` with an empty `DelegateExecute`, the
Win+E class) and the stand-in shell window that receives "Show in folder" selections follow the design
of the Files app's launcher (`Files.App.Launcher`, https://github.com/files-community/Files). Arke
contains no code from it; the implementation is written from the documented shell interfaces.

Copyright (c) Files Community. Licensed under the MIT License.

No code was copied. They were only read to understand list virtualization and file watching;
Arke's implementation is independent.
